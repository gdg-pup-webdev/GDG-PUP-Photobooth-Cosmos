## About

Cosmos-branded photobooth for GDG PUP Cosmos. Guests capture photos, apply filters, and download strips from a themed landing experience.

## Start here

- **Humans:** this README, then [docs/state.md](docs/state.md)
- **Agents:** [AGENTS.md](AGENTS.md) (state → index → FLAGS)
- **Contributors:** table below

## Features

- Camera booth capture
- Photo filters
- Photo strip downloads
- Cosmos-themed landing page

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
