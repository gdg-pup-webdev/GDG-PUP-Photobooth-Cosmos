# GDG PUP Photobooth (Cosmos)

Next.js photobooth built for **GDG PUP Cosmos**: camera booth, filters, photo strips, and a Cosmos-themed landing page.

## Table of Contents

- [About](#about)
- [Features](#features)
- [Quick start](#quick-start)
- [Documentation](#documentation)
- [Contributors](#contributors)

## About

Cosmos-branded photobooth for GDG PUP Cosmos. Guests capture photos, apply filters, and download strips from a themed landing experience.

## Features

- Camera booth capture
- Photo filters
- Photo strip downloads
- Cosmos-themed landing page

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
